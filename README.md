# Armor Loisirs Nautiques — Hommage en mer

Page vitrine de démonstration, en français, responsive et sans compilation.

## Publication avec GitHub Pages
1. Créer un dépôt public GitHub.
2. Déposer `index.html` et `logo-aln.jpg` à la racine du dépôt.
3. Ouvrir **Settings → Pages**, sélectionner **Deploy from a branch**, `main` et `/ (root)`.
4. Patienter jusqu'à l'affichage du lien GitHub Pages.

## Personnalisation avant mise en ligne
- Confirmer que l'adresse `contact@armorloisirsnautiques.fr` fonctionne et qu'elle convient comme contact public.
- Remplacer les trois photos d'illustration distantes (images.unsplash.com) par des photographies réelles et autorisées de la baie, du bateau et du prestataire. Les URL des visuels sont dans les styles CSS (`.hero`, `.story-photo`, `.landscape`). Les photos sont chargées depuis Internet, non comprises dans l'archive.
- Valider le statut juridique de l'activité, les habilitations nécessaires, les règles de sécurité, le lieu et les formalités avec la préfecture compétente et un professionnel funéraire : ne pas présenter la prestation comme commercialement disponible avant validation.
- Confirmer les détails pratiques (bateau, port de départ, nombre de passagers, accessibilité, horaires, prestation, tarifs) avant de les ajouter. Aucun tarif ou service non vérifié n'est annoncé.
